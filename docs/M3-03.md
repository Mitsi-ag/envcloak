# M3-03: Swift client evidence

The EnvCloakKit client implements the M3-03 slice of `docs/SPEC.md` and
`docs/IPC.md`. No Rust product code or protocol reservation changes.

## Delivered

- Four-byte big-endian frames, 1 byte through 1 MiB. An invalid header is
  refused before body reads. Incoming buffers start at 16 KiB, grow by
  copy and wipe, and never materialize values as Foundation `Data`.
- Strict JSON, including UTF-8, surrogate pairs, duplicate and unknown
  fields, exact unsigned 64-bit ids, and nested response schemas. Syntax
  depth and node counts are bounded and violations fail closed.
- Standard padded base64 directly into `SecretBuffer`. JSON escapes,
  noncanonical pad bits, whitespace, URL alphabet and missing padding
  are refused. Noncopyable page allocations use best-effort `mlock` and
  `memset_s` before every release, including growth and error paths.
- Fixed RPC errors discard `error.message`; status sanitizes version and
  unavailable reason. Metadata uses `DaemonText`, with an escaped display
  form and source-allowlisted access to the original. No payload logging.
- Fresh directory, parent, socket and kernel uid checks on every call,
  without repairing the directory. Close-on-exec and socket timeouts are
  set before connect. Connect and method I/O have separate monotonic
  deadlines and observe cancellation. Missing listeners differ from
  failed checks.
- Typed `status`, `lock`, `items.list`, `items.show`, `items.check`,
  `items.add`, `grants.list`, `grants.revoke`, `deny`, `audit.verify`, and
  `backup.create`. Ordinary calls serialize; lock has the second slot.
  Lock/cancellation invalidates old and queued results. Fresh calls still
  work afterward. No connection or verification verdict is cached.
- Bundled CLI runner for metadata commands, with uid-derived HOME, fixed
  PATH/LANG, null stdin, explicit working directory, JSON output, deadline
  and output cap. Failed exits never return a success result. The runner
  owns its child and keeps it unreaped while descendants can hold pipes,
  then kills its group on failure and reaps it. A failed socket initializer
  has one descriptor closer, its deinitializer; the 64-failure
  descriptor-count test detects leaks.

The app's runtime path comes from `getpwuid_r`, not launch-controlled HOME,
CFFIXED_USER_HOME, defaults or Foundation's user-directory lookup.

## Checks

`scripts/macos/test-kit.sh` runs the Rust vector writer, independent Python
oracle, and Swift XCTest suite beside a freshly built real daemon in an
isolated HOME. The daemon integration checks status, lock, grant reads and
absent-vault refusals. The success-response fixtures cover every typed
method, including nonempty item, grant, check and audit metadata; their
metadata is contract-derived and their serializer is production Rust.

The caller supplies private HOME/TMPDIR/XDG directories under a short
`/tmp` path, an empty mode-0700 `ENVCLOAK_SWIFT_VECTORS` directory, and the
lane's `CARGO_TARGET_DIR`. Run detached from agent ancestry. The suite
refuses a reused daemon HOME. Plain `swift test` reports explicit skips
when the external fixtures or real daemon are missing. CI runs the full
script, so those checks are mandatory there.

`WireTests/testFuzzHostileWireParser` is the bounded parser fuzz entrypoint:
10,000 generated byte strings, invalid UTF-8, depth limits and every prefix
of a framed response. It is runnable through Swift's `--filter` option.

The fixture-loader test found Foundation dropping a leading U+FEFF when
bridging a JSON string. Python inputs therefore include scalar numbers;
comparison inputs preserve every scalar without that Foundation bridge.
A first CLI mutation survived because the short fixture deadline hid the
exit-status fault. The repaired test requires exact failure kinds and a
longer deadline for exit and parse cases.
