Motion

Four moments and one rule. The = is drawn once, in the reveal. After that only the block moves, and it moves like a caret. Every sequence signs off the same way: two blinks, then still.

  • Caret530 ms on, 530 ms off, hard cut
  • Drawcubic-bezier(0.5,0,0,1)
  • Settlecubic-bezier(0.2,0,0,1)
  • Breathecubic-bezier(0.45,0,0.55,1)
  • Ghost20% opacity
01

Logo reveal

The = draws in, top bar first. The block lands with a hard cut, blinks twice on the caret clock, then holds still. This is the only time the = moves.

0 to 540 top bar · 180 to 720 low bar · 900 block lands · 1430 / 1960 / 2490 / 3020 blinks · rests at 3020 ms

02

Loader

Busy: the block blinks like a caret over a 20% ghost of itself. Progress: the block fills from the bottom in whole-pixel steps, and signs off with two blinks when it is full. Both are hinted for 16, 24 and 48 px.

blink 530 on / 530 off · fill steps 240 ms settle · 1/10, 1/15, 1/30 of the block per step

03

Redaction

For the site hero and onboarding. The line types in one character every 55 ms with the block riding ahead as the caret. Then the block slides back over the value and closes to one cell. The value is a fake demo string.

ready 0 to 1060 · type 1060 to 2655 · cover 3185 to 3425 · collapse to 3785 · two blinks · rests at 5905 ms

04

Approval

For the Mac app. When an agent's request waits for Touch ID, the block turns Amber and pulses once, then waits, still. Approved or dismissed, it returns to Paper. Amber only sits on Ink, so on light surfaces the mark brings its own Ink plate.

request at 600 · Amber in 120 ms · pulse to 1.1x in 180 ms, back in 420 ms · waits · release 240 ms settle

Every animation here is SVG and CSS: no script is needed to play it, and each file honours prefers-reduced-motion on its own. Durations, curves, keyframes and colours for SwiftUI are in SPEC.md, with a reference implementation in swiftui/EnvCloakMotion.swift.
